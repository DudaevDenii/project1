Home Page

My name is Deni Dudaev. I am a student at Illinois Institute of Technology in Chicago. This site is my academic and professional portfolio for Web Development. The home page introduces my interest in software engineering, cloud systems, and campus technology. The resume page is my professional resume. The third page is about the Ed Kaplan Family Institute for Innovation and Tech Entrepreneurship.

About Me

I study Information Technology and Management with a focus on backend software, Linux systems, and cloud infrastructure. I want to work as a software engineer who builds reliable services, writes tests, and understands how networks and servers support applications in production.

Chicago is a strong place to learn this work because it has universities, research labs, and technology employers. I use class projects to practice clear documentation, careful HTML, and code that other people can read.

Outside of class I follow topics such as container deployment, database design, and how large systems stay online when traffic grows. I also like walking through campus labs and seeing how students turn ideas into working prototypes.

Academic and Technical Focus

Cloud and Distributed Systems

Cloud platforms let teams run software on many machines instead of one desktop computer. I study how services scale, how data is copied between regions, and how containers help ship the same application from a laptop to a production environment.

Systems Administration and Networking

Applications depend on operating systems, routing, and access control. I practice Linux administration, basic network configuration, and monitoring so that I can explain not only application code but also the environment that runs it.

Engineering Standards

Good software is tested, documented, and reviewed. I work on writing functions that do one job well, naming things clearly, and checking my pages with the W3C HTML validator so the markup follows public web standards.

Technologies I Am Learning

  • Programming languages: Python, C++, Go, JavaScript, and SQL
  • Platforms: Microsoft Azure, Linux distributions, and Docker containers
  • Practices: automated testing, version control with Git, and performance tuning

What You Will Find on This Site

Use the bulleted list at the top of every page to move between files. index.html is this home page. resume.html is my professional resume, including education, skills, and work history. page3.html is a campus media page with a video walkthrough of engineering spaces at Illinois Tech and a photo of the Kaplan Institute.
